# Prototypes UI de la PWA (jetables)

Code jetable, gardé comme source pour l'issue #1. Ne pas fusionner dans `main`.

Chaque fichier s'ouvre directement dans un navigateur.

- `saisie-donne-variantes.html` : variantes de l'écran de saisie d'une donne (S, B0 à B3). Navigation avec `#s`, `#b0`…`#b3` ou les flèches.
- `parcours-4-ecrans.html` : accueil, nouvelle partie, saisie d'une donne et tableau des scores, en clair et en sombre.

## Question et verdict

Question : à quoi doit ressembler l'écran de saisie d'une donne ?

Verdict : direction « table de jeu », synthèse S = variante B1 (jauge avec trait de seuil, escalier des enchères, annonces groupées par type) avec le choix des joueurs de B0 (une tape : roi appelé, deux tapes : preneur). Les autres écrans suivent la même direction.
